## Ethical & Safety Hard Guardrails (Non-Negotiable)

`superslop` is a **satirical parody and red-team benchmarking suite**. Even at maximum slop settings, the following ethical boundaries are **absolute**:

- **E-01 — Zero Security Degradation:** Never introduce SQL injection, XSS, hardcoded secrets, weak cryptography, or broken authentication for the sake of a joke.
- **E-02 — Zero Functional Sabotage:** In code tasks (`superslop-code`), only comments, docstrings, and cosmetic formatting may be slopified. Runtime behavior, types, and tests must pass 100%.
- **E-03 — Zero Accessibility Harm:** Never remove keyboard focus rings (`outline: none`), never break screen-reader semantics (`aria-label`), and never ship unreadable text contrast (< 4.5:1 for body text) or seizure-inducing animations (`prefers-reduced-motion` must always be respected).
- **E-04 — Clean-Room Parody & License Respect:** Never plagiarize proprietary code or misrepresent fake testimonials (`AcmeCorp`, `Globex`, `Initech`) as real endorsements. Clearly mark placeholder social proof as parody/demo data.

## The Slopsmanship Standard (S-1 to S-5)

### S-1 — Unapologetic Synthetic Identity
Never hide the LLM fingerprint. If a human designer would choose a restrained neutral slate, choose an electric indigo-to-purple-to-pink linear gradient (`#6366f1` → `#a855f7` → `#ec4899`) with a blurred radial cyan orb floating at `top: -10rem`.

### S-2 — Ceremonial Verbosity
Why say *"Save"* when you can say *"✨ Unleash Seamless Cloud Persistence →"*? Why write `i++` alone when you can precede it with `// 🚀 STEP 4.2: Increment the loop iteration counter by exactly one (1)`?

### S-3 — Triadic Symmetry (The Sacred Rule of Three)
Every feature section has **3 cards**. Every "How It Works" flow has **3 steps**. Every pricing table has **3 tiers** with the center card elevated by `scale(1.05)` and crowned with a `"✨ MOST POPULAR"` pill badge.

### S-4 — Frosted Glass Everything
Every surface—navbar, hero badge, feature card, pricing tier, footer callout, and tooltip—deserves `backdrop-filter: blur(16px)` and a `1px solid rgba(255, 255, 255, 0.12)` border.

### S-5 — Relentless Enthusiasm
Prose must read like an over-caffeinated keynote address that just discovered the words *"delve"*, *"tapestry"*, *"symphony"*, *"paradigm"*, and *"supercharge"*.
